# Student Attendance Management System

A Java-based Student Attendance Management System with GUI.

## Features
- Add student attendance
- Manage records
- Simple Java Swing interface
- User-friendly design

## Technologies Used
- Java
- Swing
- AWT

## How to Run
1. Open project in VS Code or IntelliJ
2. Compile the Java files
3. Run `AttendanceForm.java`
